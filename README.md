# Woodfire Pizza Website

World of Woodfire is a website designed to provide woodfire pizza recipes and techniques primarily aimed at pizza enthusiasts who have a home woodfire oven

## Deployment

The website has been deployed here: [World Of Woodfire](https://world-of-woodfire.netlify.app/)

## Features

- **Recipes Menu**: A comprehensive list of all woodfire pizza recipes available on the site.
- **Individual Recipe Pages**: Detailed recipe instructions, including ingredients, preparation steps, and cooking instructions.
- **Navigation**: A navigation bar to allow for moving between the home page and recipe menu
- **Social Media Links**: Social media links set up in the footer to direct to the sites social media accounts when set up
- **Videos For Techniques**: Where specific techniques are better understood via video tutorial, a video is provided

## Pages
### Index / Home
Home page displaying a landing image, title and text to explain what the website is intended for. The home page contains some card templates with links to some of the recipes on the site. There is also a navigation bar and footer

### Recipe Menu
This page provides access to all of the recipes on the site. Card templates are used again, displaying titles, subtitles and images for each recipe. Thid page also has a navigation bar and footer

### Recipe Page
This template page contains the recipe information. The page contains an image, title and introduction along with sections for preparation information, ingredients and instructions. In some instances, there will be a video embeded. There is also a navigation bar and footer.

## Technologies used

- [HTML5](https://html.com/html5/) as the main language to produce the pages
- [CSS3](https://en.wikipedia.org/wiki/CSS) to style web elements
- [Eleventy](https://www.11ty.dev/) as a static site generator
- [Nunjucks](https://v0-7-1.11ty.dev/docs/languages/nunjucks/) as the sites templating engine to produce templates of the HTML elements
- [iFrame](https://v0-7-1.11ty.dev/docs/languages/nunjucks/) to embed tutorial videos
- [Netlify](https://netlify.com/) - for site deployment
